# Wordmark

Put your own wordmark at `wordmark.png` in this folder:

```
engine/assets/wordmark.png
```

The engine draws it small, bottom center, as a watermark (~236 px wide, opacity ~0.78). Use only a mark you own or are authorized to use. Do not use a third-party or unverified logo.

This path is listed in `.gitignore` so a private brand asset is not committed by accident. If the file is missing, the overlay hides the image.
